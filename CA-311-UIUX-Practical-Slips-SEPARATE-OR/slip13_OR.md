# Complete Figma solution

## 1. Create the OR page

1. Open the Figma Design file for Slip 13.
2. In the Pages panel create/select `03-OR`.
3. Do **not** mix this answer with the main Q2.
4. Create the required frame(s) on this page.
5. Rename every top-level frame clearly with the `OR-13-...` naming pattern.

## 2. Figma tools you will use

- **Frame:** `F` or `A`
- **Text:** `T`
- **Rectangle/shape:** `R`
- **Auto Layout:** select relevant content and press `Shift + A`
- **Component:** use the component control in the toolbar
- **Prototype:** use the Prototype tab in the right sidebar
- **Present:** test the final prototype

## 3. Build the answer step-by-step

1. Create a mobile shopping marketplace frame.
2. Add product cards with image, name, rating, price and CTA.
3. Add search.
4. Add filters.
5. Add wishlist control.
6. Add bottom navigation.
7. Create a selected/wishlisted visual state.
8. Use consistent card structure.
9. Prototype product-card navigation and wishlist behaviour where required.

## 4. Visual consistency

1. Use one consistent font family.
2. Establish a clear heading/body hierarchy.
3. Keep spacing consistent.
4. Align related elements.
5. Use the same button style for the same action.
6. Use consistent corner radius and card structure.
7. Do not use decoration that makes the required information harder to see.
8. Use realistic sample content.

## 5. Prototype connections — when applicable

1. Select the button/card/icon that should be clickable.
2. Open the **Prototype** tab.
3. Drag the node to the destination frame.
4. Choose `On click`/`On tap` as the trigger.
5. Choose `Navigate to` for normal screen navigation.
6. Use `Open overlay` for menus, filters or dialogs.
7. Choose a simple transition such as Dissolve or Smart Animate.
8. Repeat for all required interactions.
9. Set the first OR frame as the prototype starting point.
10. Click **Present**.
11. Perform the entire task as a user.
12. Fix any broken or missing interaction.
