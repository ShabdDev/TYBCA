# CA-311-MJ-P UI-UX Practical — Complete Separate OR Package

This package contains all 25 practical slips from the supplied PDF.

## File structure

Every slip has **three independent Markdown files**:

- `slipN_1.md` → Q1
- `slipN_2.md` → Q2 Main
- `slipN_OR.md` → Q2 OR

Therefore:

**25 × 3 = 75 independent practical files**

Plus `README.md` and `INDEX.md`.

## Why the OR is separate

The OR question is a complete alternative practical. It now has its own file with:

- Complete original OR question
- Separate Figma page instructions
- Frame creation
- Exact build steps
- Required screens/elements
- Prototype instructions where applicable
- Final verification checklist
- OR-specific viva questions
- Examiner explanation

## Recommended Figma pages

For each slip:

1. `01-Q1`
2. `02-Q2`
3. `03-OR`
4. `04-Viva`
