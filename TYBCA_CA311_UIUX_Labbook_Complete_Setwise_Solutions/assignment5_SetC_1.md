## Question — Design an Online Learning App

**Lab-book question:** Select app idea for Online Learning App, Define features, Design full interface, Create multiple screens, Create prototype, Add navigations and user interactions between screens.

### Solution

## 1. App idea

**App name:** LearnHub

**Purpose:** Help learners discover courses, enroll, study lessons, track progress and complete learning activities.

## 2. Features

- Login/registration
- Course search
- Course categories
- Course details
- Enrollment
- Video/lesson screen
- Progress tracking
- Quiz
- Certificates
- Profile
- Course history

## 3. Screens

### Screen 1 — Login
- Email
- Password
- Login
- Register

### Screen 2 — Home
- Search
- Categories
- Recommended courses
- Continue learning

### Screen 3 — Course list
- Course cards
- Course title
- Instructor
- Rating
- Duration

### Screen 4 — Course details
- Course title
- Description
- Instructor
- Curriculum
- Enroll button

### Screen 5 — Learning screen
- Lesson title
- Video/content area
- Previous/Next controls
- Mark complete

### Screen 6 — Quiz
- Question
- Options
- Submit
- Score/result

### Screen 7 — Progress
- Course progress
- Completed lessons
- Remaining lessons

### Screen 8 — Profile
- User information
- Enrolled courses
- Certificates

## 4. Prototype flow

```text
Login
  ↓
Home
  ↓
Course List
  ↓
Course Details
  ↓
Enroll
  ↓
Learning Screen
  ↓
Quiz
  ↓
Progress / Certificate
```

## 5. Prototype interactions

- Course card → Course Details
- Enroll → Learning Screen
- Next → Next Lesson
- Submit → Quiz Result
- Progress → Progress Screen
- Profile → Profile

### Result

A complete online learning application interface with multiple screens and prototype navigation was designed.

### Conclusion

The concepts of wireframing, UI components, navigation and interactive prototyping were applied to an online learning application.
