## Question 1 — Compare 2 apps UI/UX

**Lab-book question:** Compare 2 apps UI/UX.

### Solution

Compare **WhatsApp** and **Telegram** as examples.

| Aspect | WhatsApp | Telegram |
|---|---|---|
| Home screen | Chat-focused layout | Chat-focused layout with additional menu options |
| Navigation | Simple and familiar | Simple with additional feature access |
| Typography | Clear and readable | Clear and readable |
| Primary action | Start/open chats | Start/open chats |
| Visual hierarchy | Conversation-first | Conversation-first |
| UX | Designed around quick messaging and calls | Designed around messaging plus broader communication features |

The comparison should focus on observable interface and interaction characteristics rather than personal preference.

### Result

Two application interfaces were compared from UI and UX perspectives.

## Question 2 — Write observations

**Lab-book question:** Write observations.

### Solution

1. Both applications use recognizable messaging patterns.
2. Frequently used actions are placed where users can access them easily.
3. Consistent typography improves readability.
4. Icons provide compact visual representations of actions.
5. Navigation structure affects how quickly users find features.
6. Feedback after actions is important for user confidence.
7. Consistent spacing and alignment improve visual clarity.
8. A visually attractive interface alone does not guarantee good UX.

### Result

UI and UX observations were documented.

## Question 3 — Improve one design

**Lab-book question:** Improve one design.

### Solution

Improve a hypothetical messaging application's chat screen.

### Problems identified

- Too many secondary controls are visible.
- Message actions are visually competing with the main conversation.
- The primary action is not sufficiently prominent.
- Spacing between sections is inconsistent.

### Proposed improvements

1. Keep the conversation area visually dominant.
2. Place secondary actions in an overflow menu.
3. Make the message input area clearly identifiable.
4. Maintain consistent horizontal and vertical spacing.
5. Use one primary accent color for important actions.
6. Ensure text and controls have sufficient contrast.
7. Test the revised design with users before finalizing it.

### Result

An improved design proposal was prepared based on UI clarity and UX usability principles.
