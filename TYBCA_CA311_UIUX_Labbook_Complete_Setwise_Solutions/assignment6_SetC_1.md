## Question — Improvement

**Lab-book question:** SET C: Improvement.

### Solution

Improve the UI based on the usability-test findings and user feedback.

### Example improvement cycle

```text
Test Design
     ↓
Collect Feedback
     ↓
Identify Problems
     ↓
Prioritize Problems
     ↓
Modify UI
     ↓
Retest
```

### Example improvements

| Problem | Improvement |
|---|---|
| Search is difficult to locate | Increase search prominence |
| Navigation is confusing | Simplify navigation labels |
| Text has poor readability | Increase text size/contrast |
| Checkout contains unnecessary steps | Reduce steps |
| Success state is unclear | Add clear confirmation message |
| Elements are inconsistently aligned | Apply consistent spacing and grid alignment |

### Figma procedure

1. Duplicate the original design so the first version is preserved.
2. Mark each identified usability problem.
3. Modify the affected components.
4. Maintain consistent typography and spacing.
5. Improve contrast where necessary.
6. Update prototype connections if navigation changes.
7. Test the revised prototype again.
8. Compare the first and revised versions.

### Result

The UI was improved using findings from usability testing and user feedback.

### Conclusion

UI/UX design is iterative. Testing identifies problems, feedback explains the user's experience, and iteration improves the design.
