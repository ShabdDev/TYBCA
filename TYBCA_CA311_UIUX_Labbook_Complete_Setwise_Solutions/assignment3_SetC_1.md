## Question — Create user flow

**Lab-book question:** SET C: User flow.

### Solution

Create a user flow for ordering food through a mobile application.

### User flow

```text
Start
  |
  v
Home Screen
  |
  v
Search / Select Category
  |
  v
Restaurant List
  |
  v
Restaurant Details
  |
  v
Select Food Item
  |
  v
Add to Cart
  |
  v
Cart
  |
  v
Checkout
  |
  v
Payment
  |
  v
Order Confirmation
  |
  v
Track Order
  |
  v
End
```

### Procedure

1. Define the user goal: order food.
2. Identify the starting screen.
3. List every major action needed to complete the task.
4. Connect screens in logical order.
5. Identify decision points such as item selection and payment.
6. Add an error/alternate path where useful.

### Example alternate flow

```text
Payment
   |
   +---- Payment successful ----> Order Confirmation
   |
   +---- Payment failed --------> Retry Payment
```

### Result

A user flow showing the major steps from opening the application to tracking the order was created.

### Conclusion

User flows help designers understand navigation and identify unnecessary or missing steps before implementation.
