## Question 1 — Identify UI/UX examples from apps

**Lab-book question:** Identify UI/UX examples from apps.

### Solution

UI and UX are related but different:

- **UI (User Interface):** The visible and interactive part of an application — buttons, colors, typography, icons, forms, spacing, and layout.
- **UX (User Experience):** The overall experience of using the application — ease of navigation, clarity, efficiency, feedback, and user satisfaction.

The lab book uses a login screen as an example: the visual elements of the login screen represent UI, while how easy it is for a user to log in represents UX.

### Examples

| App / Product | UI Example | UX Example |
|---|---|---|
| WhatsApp | Chat list, send button, message bubbles, icons | Easy access to recent chats and quick message sending |
| YouTube | Video thumbnails, navigation bar, play controls | Search and recommendation flow helps users find videos |
| Google Maps | Map, search box, location marker, route buttons | Step-by-step navigation helps users reach a destination |
| Amazon | Product cards, search bar, cart icon, filters | Product search, filtering, cart and checkout flow |
| Spotify | Album artwork, player controls, navigation tabs | Easy music discovery and continuous playback |

### Observation

A good UI makes controls and information visually understandable. A good UX makes the complete task easy and efficient. Therefore, UI is one important part of the overall UX.

### Result

UI/UX examples were identified from commonly used applications, and the difference between visual interface elements and user experience was understood.

## Question 2 — Create basic Figma account

**Lab-book question:** Create basic Figma account.

### Solution

1. Open a web browser such as Chrome, Edge, or Firefox.
2. Visit the official Figma website: `https://www.figma.com`
3. Select **Get Started for Free**.
4. Sign up using a Google account or email ID.
5. Complete the account setup.
6. Log in to Figma.
7. The Figma dashboard is displayed.
8. Select **New Design File** to create a design file.

### Result

A basic Figma account was created successfully and a new design file was opened.

## Question 3 — Explore design interface

**Lab-book question:** Explore design interface.

### Solution

Open a new Figma design file and identify the major areas:

1. **Toolbar:** Contains tools such as Move, Frame, Shape, Pen, Text, and other design controls.
2. **Canvas:** Main working area where frames and design objects are created.
3. **Layers panel:** Displays frames, groups, shapes, text and other objects.
4. **Design/Prototype/Inspect area:** Provides properties and interaction-related controls.
5. **Properties:** Used to modify dimensions, position, alignment, fill, stroke, typography, effects, and other attributes.
6. **Frame:** Represents a screen or container such as a mobile screen.
7. **Prototype connections:** Used to connect screens and define interactions.

### Practical exploration

Create a mobile frame and add:

- One heading using the Text tool.
- Two rectangular input fields.
- One button.
- One icon or simple shape.

Move the elements, change their size, align them, and inspect their properties.

### Result

The main Figma design interface and its basic tools were explored successfully.
