## Question — Feedback

**Lab-book question:** SET B: Feedback.

### Solution

Collect structured feedback from users after usability testing.

### Feedback questions

1. Was the main task easy to complete?
2. Which screen was easiest to understand?
3. Which screen was confusing?
4. Were the buttons and labels understandable?
5. Was the navigation clear?
6. Was the text readable?
7. Did you encounter any error or unexpected behavior?
8. What would you change?
9. Was any information missing?
10. Rate the ease of use from 1 to 5.

### Feedback record

| Area | User feedback | Design implication |
|---|---|---|
| Navigation | Example: User could not find Orders | Make Orders easier to discover |
| Labels | Example: Button wording unclear | Use more descriptive labels |
| Layout | Example: Too much information | Simplify the screen |
| Readability | Example: Text too small | Increase typography size |
| Interaction | Example: No clear confirmation | Add feedback after actions |

### Procedure

1. Conduct the usability test.
2. Ask the feedback questions.
3. Record responses.
4. Group similar feedback.
5. Identify recurring problems.
6. Convert feedback into design changes.

### Result

Structured user feedback was collected and categorized.

### Conclusion

User feedback provides evidence for deciding which parts of the interface should be refined.
