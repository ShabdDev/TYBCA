## Question — Create a paper wireframe

**Lab-book question:** SET A: Paper wireframe.

### Solution

Create a low-fidelity paper wireframe for a **mobile food delivery home screen**.

### Wireframe structure

Draw the following boxes and labels using pencil/pen. Do not focus on colors or visual decoration.

```text
+--------------------------------+
| Location              Profile  |
|                                |
| [ Search restaurants/food ]    |
|                                |
| Categories                     |
| [Pizza] [Burger] [Biryani]     |
|                                |
| Popular Restaurants            |
| +----------------------------+ |
| | Image                      | |
| | Restaurant Name             | |
| | Rating   Delivery Time      | |
| +----------------------------+ |
|                                |
| +----------------------------+ |
| | Image                      | |
| | Restaurant Name             | |
| | Rating   Delivery Time      | |
| +----------------------------+ |
|                                |
| Home   Search   Orders  Profile|
+--------------------------------+
```

### Procedure

1. Take a blank sheet of paper.
2. Draw the mobile screen boundary.
3. Draw a header.
4. Add a search box.
5. Add category placeholders.
6. Add restaurant-card rectangles.
7. Add bottom navigation.
8. Label each component.
9. Check whether the layout supports the intended user task.

### Result

A low-fidelity paper wireframe was created.

### Conclusion

The paper wireframe helped plan the structure before visual styling.
