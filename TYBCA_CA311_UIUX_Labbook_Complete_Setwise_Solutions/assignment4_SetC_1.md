## Question — Create responsive design

**Lab-book question:** SET C: Responsive design.

### Solution

Create mobile and desktop versions of the same application and define how the layout changes between screen sizes.

### Responsive rules

| Component | Mobile | Desktop |
|---|---|---|
| Header | Compact | Wider navigation |
| Restaurant cards | 1–2 columns or vertical list | Multiple columns |
| Categories | Horizontal scrolling or compact row | Full row |
| Navigation | Bottom navigation | Header/sidebar navigation |
| Content width | Narrow | Constrained maximum width |
| Images | Smaller | Larger |
| Spacing | Compact | More generous |

### Procedure

1. Create the mobile design.
2. Duplicate the design for desktop.
3. Change frame dimensions.
4. Rearrange components to use available space.
5. Apply a column grid to the desktop frame.
6. Adjust typography and spacing.
7. Check that important information remains visible.
8. Preview both versions.

### Visual design checks

- Consistent color palette.
- Consistent typography.
- Sufficient contrast.
- Consistent spacing.
- Clear hierarchy.
- Aligned components.

### Result

A responsive design showing mobile and desktop adaptations was created.

### Conclusion

The same product experience can be maintained while the layout adapts to different screen sizes.
