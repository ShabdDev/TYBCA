## Question — Design desktop UI

**Lab-book question:** SET B: Desktop UI.

### Solution

Convert the mobile food delivery design into a desktop layout.

### Desktop structure

```text
+----------------------------------------------------------------+
| Logo | Location | Search restaurant/food | Orders | Profile    |
+----------------------------------------------------------------+
| Categories                                                     |
+----------------------------------------------------------------+
|                    Promotional Banner                          |
+----------------------------------------------------------------+
| Popular Restaurants                                            |
| +------------+ +------------+ +------------+ +------------+   |
| | Restaurant | | Restaurant | | Restaurant | | Restaurant |   |
| | Image      | | Image      | | Image      | | Image      |   |
| | Rating     | | Rating     | | Rating     | | Rating     |   |
| +------------+ +------------+ +------------+ +------------+   |
+----------------------------------------------------------------+
```

### Figma implementation

1. Create a desktop frame.
2. Apply a column layout grid.
3. Create a wider header.
4. Place categories horizontally.
5. Use multiple restaurant cards across the available width.
6. Maintain consistent gutters and spacing.
7. Ensure content does not become excessively wide.
8. Compare the desktop screen with the mobile design.

### Result

A desktop UI was created by adapting the mobile interface to a wider screen.
