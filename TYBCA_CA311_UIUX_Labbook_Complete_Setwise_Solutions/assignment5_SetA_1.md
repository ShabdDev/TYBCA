## Question — Design a Food Delivery App

**Lab-book question:** Select app idea for Food Delivery App, Define features, Design full interface, Create multiple screens, Create prototype, Add navigations and user interactions between screens.

### Solution

## 1. App idea

**App name:** QuickBite

**Purpose:** Allow users to discover restaurants, select food, place an order, pay, and track delivery.

## 2. Define features

- User registration/login
- Location selection
- Restaurant search
- Category browsing
- Restaurant details
- Food item selection
- Cart
- Checkout
- Payment
- Order confirmation
- Order tracking
- Order history
- Profile

## 3. Design full interface

Create the following screens in Figma:

### Screen 1 — Login

- Logo
- Email/phone
- Password
- Login button
- Sign-up option

### Screen 2 — Home

- Location
- Search
- Categories
- Promotional banner
- Popular restaurants

### Screen 3 — Restaurant list

- Restaurant cards
- Rating
- Delivery estimate
- Cuisine/category
- Filters

### Screen 4 — Restaurant details

- Restaurant image
- Name
- Rating
- Delivery information
- Menu items
- Add button

### Screen 5 — Cart

- Selected items
- Quantity controls
- Subtotal
- Delivery fee
- Total
- Checkout button

### Screen 6 — Checkout

- Delivery address
- Payment method
- Order summary
- Place order button

### Screen 7 — Order confirmation

- Success message
- Order number
- Estimated delivery
- Track order button

### Screen 8 — Order tracking

- Order status
- Progress indicator
- Delivery estimate
- Contact/help option

## 4. Create prototype

Connect screens:

```text
Login
  ↓
Home
  ↓
Restaurant List
  ↓
Restaurant Details
  ↓
Cart
  ↓
Checkout
  ↓
Order Confirmation
  ↓
Order Tracking
```

## 5. Add navigation and interactions

In Figma Prototype mode:

- Login button → Home
- Restaurant card → Restaurant Details
- Add to Cart → Cart
- Checkout → Checkout
- Place Order → Order Confirmation
- Track Order → Order Tracking
- Back controls → Previous screen

Use suitable interaction triggers such as click/tap and transitions.

## 6. Testing checklist

Verify:

- Every primary button has a destination.
- Back navigation works.
- No screen is isolated accidentally.
- Labels are understandable.
- The main ordering flow can be completed.

### Result

A complete food delivery UI project with multiple screens and prototype navigation was designed.

### Conclusion

The complete UI design process — idea, design and prototype — was applied to a practical application.
