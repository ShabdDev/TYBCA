## Question — Design mobile UI

**Lab-book question:** SET A: Mobile UI.

### Solution

Design a mobile UI for a food delivery application.

### Mobile frame

Create a mobile frame in Figma and include:

1. Header with location and profile.
2. Search field.
3. Food categories.
4. Promotional/banner area.
5. Popular restaurant cards.
6. Bottom navigation.

### Suggested visual hierarchy

- Large heading/section title.
- Prominent search control.
- Restaurant image as the main visual.
- Restaurant name and rating below the image.
- Delivery information in readable text.
- Bottom navigation with clearly recognizable icons.

### Responsive considerations

- Use touch-friendly controls.
- Avoid very small text.
- Maintain consistent margins.
- Keep important actions within comfortable thumb reach.
- Use a column structure appropriate for a narrow screen.

### Result

A mobile UI was designed with a clear hierarchy and touch-oriented layout.
