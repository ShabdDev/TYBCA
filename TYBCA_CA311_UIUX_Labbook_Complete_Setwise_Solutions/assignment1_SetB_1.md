## Question 1 — Create simple login screen

**Lab-book question:** Create simple login screen.

### Solution

Create a mobile login screen in Figma.

### Screen structure

1. Create a mobile-sized **Frame**.
2. Add the application/logo area at the top.
3. Add heading: **Welcome Back**
4. Add supporting text: **Please sign in to continue.**
5. Add **Username / Email** input field.
6. Add **Password** input field.
7. Add **Login** button.
8. Optionally add **Forgot Password?**
9. Add **Don't have an account? Sign Up** at the bottom.

### Suggested layout

```text
+-----------------------------+
|            Logo             |
|                             |
|        Welcome Back         |
|   Please sign in to continue|
|                             |
|  Email / Username           |
|  [_______________________]  |
|                             |
|  Password                   |
|  [_______________________]  |
|                             |
|       [     LOGIN     ]     |
|                             |
|       Forgot Password?      |
|                             |
| Don't have an account?      |
|          Sign Up            |
+-----------------------------+
```

### Result

A simple login screen was designed in Figma.

## Question 2 — Apply colors and fonts

**Lab-book question:** Apply colors and fonts.

### Solution

Apply a consistent visual system.

**Suggested colors:**

| Element | Suggested value |
|---|---|
| Background | `#F8F9FA` |
| Primary button | `#2563EB` |
| Button text | White |
| Heading | `#111827` |
| Secondary text | `#6B7280` |
| Input border | `#D1D5DB` |

**Suggested typography:**

- Heading: Inter / Poppins, 24 px, Semibold
- Body: Inter / Poppins, 14–16 px, Regular
- Button: Inter / Poppins, 14–16 px, Medium

### Design rules

1. Use a limited color palette.
2. Maintain sufficient contrast.
3. Use the same font family throughout the screen.
4. Use larger text for important headings.
5. Keep consistent spacing between fields.

### Result

Colors and typography were applied consistently to the login screen.

## Question 3 — Use basic shapes

**Lab-book question:** Use basic shapes.

### Solution

Use Figma shape tools to construct interface elements.

1. Use a **Rectangle** for the input fields.
2. Use a rounded rectangle for the Login button.
3. Use a **Circle/Ellipse** for the profile or logo placeholder.
4. Use lines or simple rectangles for separators.
5. Use text objects for labels.
6. Align all shapes using Figma alignment controls.
7. Group related elements where appropriate.

### Result

Basic shapes were used to construct the login interface.
