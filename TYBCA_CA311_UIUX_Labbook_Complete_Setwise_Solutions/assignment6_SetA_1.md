## Question — Testing

**Lab-book question:** SET A: Testing.

### Solution

Perform usability testing on the previously designed application prototype.

### Test objective

Determine whether a user can complete the primary task without unnecessary confusion or errors.

### Test task

For the food delivery prototype:

> Find a restaurant, select a food item, add it to the cart and reach the order confirmation screen.

### Test procedure

1. Select 3–5 representative test users where possible.
2. Explain the task without explaining how to perform it.
3. Give the user the prototype.
4. Observe the user's actions.
5. Record where the user hesitates or makes an error.
6. Record whether the user completes the task.
7. Ask brief follow-up questions.
8. Summarize the findings.
