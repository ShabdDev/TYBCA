## Question — Design a Hospital Appointment Booking App

**Lab-book question:** Select app idea for Hospital Appointment Booking App, Define features, Design full interface, Create multiple screens, Create prototype, Add navigations and user interactions between screens.

### Solution

## 1. App idea

**App name:** CareBook

**Purpose:** Allow patients to find doctors, select appointments, provide required details and receive booking confirmation.

## 2. Features

- Login/registration
- Doctor search
- Specialty selection
- Hospital selection
- Doctor profile
- Available dates and times
- Appointment booking
- Patient details
- Booking confirmation
- Appointment history
- Profile

## 3. Screens

### Screen 1 — Login
- Email/mobile
- Password
- Login
- Register

### Screen 2 — Home
- Search doctor/hospital
- Specialties
- Nearby hospitals
- Upcoming appointment

### Screen 3 — Doctor search
- Doctor cards
- Specialty
- Hospital
- Experience/details
- Available appointment indicator

### Screen 4 — Doctor profile
- Doctor name
- Specialty
- Hospital
- Professional information
- Available slots
- Book appointment

### Screen 5 — Appointment slot
- Date selector
- Available time slots
- Confirm selection

### Screen 6 — Patient details
- Patient name
- Age
- Contact information
- Required notes

### Screen 7 — Confirmation
- Doctor
- Hospital
- Date
- Time
- Booking confirmation
- Appointment ID

### Screen 8 — Appointment details
- Appointment status
- Date/time
- Hospital/doctor
- Reschedule/cancel options

## 4. Prototype flow

```text
Login
  ↓
Home
  ↓
Doctor Search
  ↓
Doctor Profile
  ↓
Select Slot
  ↓
Patient Details
  ↓
Confirmation
  ↓
Appointment Details
```

## 5. Figma interactions

Connect primary actions using Prototype mode:

- Login → Home
- Search result → Doctor Profile
- Book Appointment → Select Slot
- Confirm Slot → Patient Details
- Continue → Confirmation
- View Appointment → Appointment Details

### Result

A complete hospital appointment booking interface and prototype flow were created.

### Conclusion

User-centered interface design and interactive prototyping were applied to a healthcare appointment workflow.
