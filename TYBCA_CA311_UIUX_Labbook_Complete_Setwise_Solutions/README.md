# CA-311-MJ-P UI/UX Design Lab Book — Complete Set-wise Solutions

This folder contains all 18 set-wise Markdown solutions for the SPPU T.Y.B.Sc.(Computer Applications) / T.Y.B.C.A. Semester-V CA-311-MJ-P UI/UX Design Lab Workbook.

## File naming

- `assignment1_SetA_1.md`
- `assignment1_SetB_1.md`
- `assignment1_SetC_1.md`
- ...
- `assignment6_SetC_1.md`

Each file contains:
1. The complete lab-book question for that set.
2. A practical solution.
3. Procedure/steps where applicable.
4. Result and conclusion.
5. Tables/flows/templates where useful.

For tasks requiring Figma/Google Forms, the Markdown gives the exact practical design/content to create. Actual screenshots should be added to the journal after performing the work.
